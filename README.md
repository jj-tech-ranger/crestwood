# Crestwood University Student Information Portal

Crestwood University is a fictional comprehensive university in South Africa. This website was created as an academic HTML5, CSS and JavaScript demonstration.

## University

Name: Crestwood University

Location: Johannesburg, Gauteng, South Africa

Motto: Knowledge. Innovation. Impact.

Established: 1998

Students: 12,000

Faculties: 6

Academic Programmes: 120+

Study Levels: Undergraduate, Honours, Master's and PhD

## Website Pages

index.html

The home page contains the university welcome message, hero image, navigation, university statistics, images, multimedia video and application call-to-action.

about.html

The About Us page contains the fictional university history, mission, vision, motto and six faculties.

programmes.html

The Programmes page contains academic information and a programme table showing faculties, qualifications, durations and study levels.

services.html

The Services page contains student counselling and wellness, career guidance, accommodation, financial aid, sports and recreation, and academic advising.

application.html

The Application page contains a demonstration university application form.

The form includes:

- First name
- Surname
- Date of birth
- Email address
- Telephone number
- South African ID or passport number
- Nationality
- Gender radio buttons
- Study level
- Faculty
- Programme
- Intake year
- Financial aid
- Document checklist
- Motivation textarea
- Submit button
- Reset button

The programme list changes according to the selected faculty.

The form validates required fields, email addresses and telephone numbers.

A fictional application reference is generated after successful submission.

No application data is stored or sent to a server.

contact.html

The Contact Us page contains the fictional university address, email, telephone number, admissions email, office hours and a demonstration contact form.

## Application Demonstration

The application form is only a front-end demonstration.

It does not:

- Store application information
- Send information to a database
- Send emails
- Upload documents
- Connect to a backend

Successful submission generates a temporary fictional reference number using JavaScript.

## Contact Form Demonstration

The contact form is also front-end only.

It validates the information and displays a success message but does not send an actual email.

## Running the Website

Keep the folder structure unchanged.

Open index.html in a modern web browser.

For the video to work, place the generated MP4 file in the media folder using the filename:

crestwood-intro.mp4

Make sure all image filenames match the filenames referenced in the HTML files.
